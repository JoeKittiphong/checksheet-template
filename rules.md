# 📜 Project Rules & Guidelines

- **Style**: Strictly follow the reference images (Industrial/Solid look). No unintended decorations.
- **Components**: Check for existing components (especially SQR versions) before creating new ones.
- **Logic**: Maintain measurement logic (e.g., 3-point checks) unless explicitly told otherwise.
- **Documentation**: Update `components.md` when a new pattern is established or learned.
- **Communication**: Ask for confirmation before creating non-code artifacts or starting complex research.
